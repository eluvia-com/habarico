The Python side of Habarico ships as two packages under two different licences.

| Package | Licence | What it covers |
|---|---|---|
| `habarico` | [MIT](https://opensource.org/license/mit) | the free library — admin classes, schema generation, filtering, views, user preferences |
| `habarico-enterprise` | Commercial, proprietary | the paid extensions — [aggregations](./aggregations/index.md), [dashboard](./dashboard.md), [global search](./filtering-and-searching/global-search.md), [AI integration](./ai-integration/index.md), [change history](./change-history-reversion.md), [chunked uploads](./chunked-uploads/index.md), CZ model fields |

## habarico — MIT

Copyright © Eluvia.land s.r.o. Use, copy, modify and distribute it under the terms in the
`LICENSE` file shipped with the package.

## habarico-enterprise — commercial

Use, copying and distribution are permitted **only under a valid licence agreement with
Eluvia.land s.r.o.** Installing it alongside the MIT library does not place any part of it under
MIT, and the paid package is not redistributable on its own.

Pages documenting a paid feature carry a **premium** badge, so what needs a licence is visible
before you build on it.
