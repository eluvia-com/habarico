title: View components
sidebar_position: 1
---

One component per view type. Each one reads the schema of its view and renders the fields, inputs
and actions the backend declared, so a resource usually needs none of them written by hand — they
are the escape hatch for the cases that do.

| Page | What it covers |
| --- | --- |
| [SchemaList](./schema-list-component.md) | The list (index) view |
| [SchemaShow](./schema-show-component.md) | The read-only detail view |
| [SchemaCreate](./schema-create-component.md) | The create form |
| [SchemaEdit](./schema-edit-component.md) | The edit form |
| [SchemaAction](./schema-action-component.md) | Custom action views |
| [View slots](./view-slots-title-toolbar-actions-form-actions-list-actions.md) | Injecting your own title, toolbar and form actions |
